# C++ Vehicle Rental System

A console-based Vehicle Rental System developed using C++ and Object-Oriented Programming concepts.

The application allows users to add vehicles, view vehicles, search by vehicle ID, rent vehicles, and return rented vehicles.

## Features

- Add cars and bikes
- View all vehicles
- Search vehicle by ID
- Rent a vehicle
- Calculate rental cost
- Return a vehicle
- Track vehicle availability
- Exit the application

## Technologies Used

- C++
- STL Vector
- Object-Oriented Programming

## Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Polymorphism
- Virtual Functions
- Function Overriding
- Access Specifiers
- Pointers
- Dynamic Memory Allocation
- Vector
- Loops and Conditional Statements
